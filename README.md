A short vertical TikTok video about the same tiny agent-built game on the
day it was made and after a week of daily updates. The game is Cinderfall,
a duel card game my AI agent built: day one, one enemy, four slots,
sixteen cards. Seven days of daily updates later — same game, same start —
six slots, new cards, a second enemy (the Cinder Matron), floating embers
and a resonance counter. The camera never moves; the change is the whole
story. It closes on the newer build being played and an invitation to start
yours at make.fun, then make.fun's referral end card with referral code
`v39fpzhh`.

The video itself is the entry; the house reads it from TikTok. This
repository holds `VIDEO.json` (the video's URL) and `main.ts`, which copies
`VIDEO.json` to `/output` when run. The rendered video is
`day-one-day-seven.mp4` (1080x1920, ~27 seconds, with a voiceover and
on-screen text, make.fun's brand badge from the first frame, and the
referral end card at the end).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
